# AI嵌入式助手 使用文档

> 上位机（主机侧）软件：串口/RTT 调试 + 波形查看 + 数据录制 + AI 联动。
> 软件本身与固件业务无关，可连接任何串口/RTT 设备；文中“应用案例”一节用温度控制仿真演示完整用法。
> 全流程分工：**编辑代码 → 编译/下载（eide-mcp-skill）→ 调试/验证（本软件）**；AI 操作本软件（MCP）的方法见 `skills/ai-embedded-assistant/SKILL.md`，仓库结构与安装见根 `README.md`。

---

## 1. 软件能做什么

| 能力 | 说明 |
|---|---|
| 串口调试 | 打开/关闭串口、HEX/文本收发、时间戳、自动换行/滚动、接收区保存与历史加载 |
| RTT 调试 | 调试探针（J-Link 或 DAPLink/CMSIS-DAP）连接后：ch0 Shell 交互、ch1 波形、ch2 设备日志（按级别着色） |
| 波形查看 | JustFloat 多通道解析 + 通道重命名 + TCP VoFA 转发给 VOFA+ |
| 数据录制 | 浮点通道定时快照写 CSV（时长/采样率/保存目录可设） |
| AI 联动 | 数据可推送 DSH 会话；同时暴露 MCP 服务，AI 可直接下发命令/调参/读日志 |
| 页面风格 | 深色 / 浅色（白底橙黑）切换 |

## 2. 安装与运行

### 2.1 方式一：安装包 / 绿色版
- 安装包：`software/dist/dist-installer\AIEmbeddedAssistant-Setup.exe`（向导安装，可自选安装目录、可选桌面快捷方式）。
- 绿色版：`software/dist/dist\AIEmbeddedAssistant\AIEmbeddedAssistant.exe`（拷走即用）。

### 2.2 方式二：源码运行
```bash
cd software/code   # 软件源码在本仓库 software/code 下
pip install -r requirements.txt
python main.py
```

### 2.3 外部依赖
| 依赖 | 用途 | 说明 |
|---|---|---|
| **SEGGER J-Link 软件** | RTT（J-Link 探针） | 程序自动搜索：`~\.eide\tools\jlink\JLink_x64.dll` → `C:\Program Files\SEGGER\JLink\...` → 配置键 `rtt_jlink_dll` |
| **pyOCD**（Python 包） | RTT（DAPLink 探针） | `pip install pyocd`；Windows 上 DAPLink 还需 WinUSB 驱动 |
| **串口驱动** | 串口模式 | CH340 / J-Link CDC 等按硬件安装 |
| Python 三方库 | 全部 | 已打进安装包，无需另装 |

> RTT 与探针无关（控制块在目标 RAM）：**J-Link 走 pylink，DAPLink/任意 CMSIS-DAP 走 pyOCD**，二者在「RTT / 调试探针设置」里切换。

## 3. 四种运行模式（顶部“运行模式”切换，即时生效）

| # | 模式 | 通道 | 界面 | 用途 |
|---|---|---|---|---|
| 1 | 串口交互 | 串口 | 串口控制台 | 普通串口收发 |
| 2 | 串口 + TCP VoFA 转发 | 串口 | 串口控制台 + 波形面板 | 串口波形送 VOFA+ |
| 3 | RTT Shell 交互 | RTT ch0/ch2 | RTT 控制台 | Shell + 设备日志 |
| 4 | RTT Shell + 波形 + TCP VoFA | RTT ch0~ch2 | RTT 控制台 + 波形面板 | 固件调试一体 |

模式 = 数据流路由器：切换时自动加载/卸载插件并重载 AI 工具集。

模式相关配置：
- **串口连接**（仅模式 1/2）：端口/刷新、波特率、高级设置（数据位/停止位/校验位/流控/断线自动重连）、打开串口。
- **RTT / 调试探针设置**（仅模式 3/4）：探针（J-Link / DAPLink）、接口（SWD/JTAG）、速度 kHz、序列号·UID、控制块地址；
  J-Link 另填芯片型号 / DLL 路径，DAPLink 另填 pyOCD 目标名 / 固件 ELF。
- **AI 联动**（全模式）：数据推送到 DSH（串口模式推接收数据；RTT 模式推 Shell 输出，AI 自己命令的响应不推）。
  前置要求：DSH 侧的 MCP / `ai-embedded-bridge` 插件在线、本软件内置 MCP 服务已启动——详见 §7「AI 联动 / MCP 前置要求」。

## 5. 串口模式使用（模式 1/2）

1. 「串口连接」：选端口 → 波特率 → 打开串口。
2. 发送区：文本或 HEX 勾选、编码选择（UTF-8/GBK…）、是否追加换行（CR/LF/CRLF）、定时循环发送。
3. 接收区：按需勾选 HEX 显示 / 时间戳 / 自动换行 / 自动滚动 / 显示接收·发送；可保存到文件、打开历史文件回看。
4. 波形与录制（模式 2）：
   - **TCP 转发**：启动服务端（默认 127.0.0.1:9000），VOFA+ 以 TCP 客户端连入（协议 JustFloat、通道数=固件通道数）。
   - **JustFloat 解析**：开启后自动切帧；可一键套用文档通道名或自定义重命名。
   - **浮点录制**：设默认时长/采样率（建议 ≥20Hz），开始/暂停/继续/结束；CSV 表头使用重命名后的通道名。

## 6. RTT 模式使用（模式 3/4）

1. 「RTT / 调试探针设置」选探针（J-Link 或 DAPLink）→ 确认接口/速度 → **连接 RTT**。
   - J-Link：填芯片型号（如 STM32H743XI），DLL 留空自动搜索。
   - DAPLink：填 pyOCD 目标名（如 stm32h743xx），建议填固件 `.axf` 路径（解析 `_SEGGER_RTT`）；留空则自动扫描目标 RAM 找控制块。
2. **Shell 交互**：下方输入行回车发送（固件以 `\r` 触发执行）。常用：
   ```
   help / h        查看命令
   <cmd> -h        查看某命令用法
   ```
3. **设备日志**：ch2 日志自动进控制台并按级别着色（与下位机 log_config.h 一致）：
   `DEBUG` 蓝 / `INFO` 绿 / `WARN` 黄 / `ERROR` 红 / `FATAL` 品红（加粗）。
   Shell 输出与日志可分别勾选“显示 Shell / 显示 Log”。
4. **波形**（模式 4）：RTT ch1 JustFloat → 可转发 TCP 给 VOFA+，或浮点录制存 CSV。

> 提示：设备复位后 RTT 会话会失效——烧录后请“断开 RTT → 重新连接”，ch2 日志才会继续送达。

## 7. 配置文件

默认 `~/.ai_embedded_assistant/config.yaml`（BOM 健壮，兼容旧 config.json；旧 `~/.serial_assistant` 目录可整体改名/拷贝迁移）。关键键：
- `mode`：serial / serial_vofa / rtt_shell / rtt_vofa
- `theme`：dark / light
- 串口：`port/baudrate/bytesize/parity/stopbits/flow`
- RTT：`rtt_probe`（jlink/dap）、`rtt_chip/rtt_interface/rtt_speed/rtt_serial_no/rtt_control_block_addr`
  - DAPLink 专属：`rtt_dap_target`（pyOCD 目标名）、`rtt_dap_elf`（固件 .axf）、`rtt_cb_search_addr/size`（控制块扫描范围）
- 波形/录制：`justfloat_enabled/justfloat_channel_names/csv_dir/csv_duration_s/csv_sample_hz`
- AI：`ai_server_enabled/ai_server_host/ai_server_port/ai_push_enabled/ai_push_mode/ai_push_url`

「设置 ▾ → 加载/保存配置」读写任意 .yaml/.json；加载后界面实时应用（含模式热切换）。

### 7.1 AI 联动 / MCP 前置要求

「AI 联动」与“让 AI 打开并操作本软件”都依赖以下环境，缺一不可：

| 前置项 | 说明 / 检查点 |
|---|---|
| **DSH（DeepSeek Harness）正在运行** | AI 侧会话本体；本机默认 `127.0.0.1:3080` |
| **DSH 的 ai-embedded-bridge 插件已加载** | 仓库内 `dsh_plugin/ai-embedded-bridge/`（Node，装到 DSH 的 `node_modules/ai-embedded-bridge`）；负责接收本软件推送的数据（默认路径 `http://127.0.0.1:3080/plugins/ai-embedded-bridge/incoming`） |
| **本软件内置 MCP 服务开启** | 配置 `ai_server_enabled: true`、`ai_server_host/port`（默认 `127.0.0.1:8765`）；启动日志出现 “AI 接口已启动” 即就绪 |
| **AI 联动推送开关** | 勾选“推送数据到 DSH” + 模式 `chat`（会话）/ `monitor`（监听）；`ai_push_enabled/mode/url` 可在配置里管理 |
| **运行模式约束** | 串口+VoFA 模式自动禁用推送（JustFloat 数据只走录制 CSV，不注入 AI）；RTT 模式推送 Shell 输出 |

典型使用链路（自检顺序）：
1. DSH 启动并加载 ai-embedded-bridge 插件；
2. 启动本软件（MCP 8765 就绪）；
3. GUI 顶部切到目标运行模式，连接串口或调试探针（J-Link/DAPLink）；
4. 勾选 AI 联动（被禁用时悬浮提示会给出原因）；
5. 对 DSH 说“帮我连 RTT / 下发命令 / 录制并分析”，AI 即通过 8765 的 MCP 工具操作。

> 调试模式下 AI 只能使用经校验的指令工具（不能发任意字节），实时波形数据通过录制 CSV 提供给 AI 分析。

## 8. 常见问题（FAQ）

1. **LED 任务里加的 LOG 不显示？**
   下位机需先调用 `LOG_Init()`（注册 `SEGGER_RTT_ConfigUpBuffer(2,"log",...)`）；未注册时 ch2 写入被静默丢弃。烧录后主机侧还需重连一次 J-Link。
2. **ch2 日志丢行？**
   固件端约 1KB + NO_BLOCK_SKIP，主机长时间未读时旧日志被覆盖；在线看无影响。
3. **RTT 连不上？**
   - J-Link：安装 SEGGER J-Link 软件，或配置 `rtt_jlink_dll` 指向 JLink DLL。
   - DAPLink：确认已 `pip install pyocd`、探针已插好且 Windows 驱动为 WinUSB；`rtt_dap_target` 填对（STM32H743 为 `stm32h743xx`）。
   - 提示“未找到 RTT 控制块”：填 `rtt_dap_elf` 指向固件 .axf，或直接填 `rtt_control_block_addr`（可用 map/ELF 查 `_SEGGER_RTT`）。
4. **RTT 模式看不到串口连接栏？**
   设计如此：串口连接只在模式 1/2 显示。
5. **退出时 uvicorn CancelledError 堆栈？**
   无害收尾噪音，不影响功能。

## 9. 应用案例：用命令+波形+录制完成一次闭环调参

> 以下是一个真实案例（HC_CPB 温度控制仿真：目标温度闭环、JustFloat 上报 8 通道），
> 演示“Shell 命令下发 → 波形观察 → CSV 录制分析”的完整闭环。**案例仅作参考，不是通用操作步骤。**

### 9.1 案例背景
固件通过 J-Link RTT 提供：
- ch0 Shell：`pid kp ki kd`、`temp_tar`、`temp_sw 0/1`、`show` 等；
- ch1 JustFloat：`temp_kp/ki/kd/sw/tar/value/current/timestamp` 8 通道 100Hz；
- ch2 日志：按级别输出。

### 9.2 操作过程（模式 4）
1. 连接 J-Link（芯片 STM32H743XI / SWD / 4000kHz）；
2. Shell 下发参数并确认：
   ```
   pid            # 查看当前：kp/ki/kd
   pid 10 0.12 2  # 设置候选参数
   temp_tar 45    # 目标温度
   show           # 查看温度/电流/开关
   ```
3. 波形面板确认 8 通道命名正确、数值实时刷新；
4. 录制：采样 20~50Hz、时长 10s → 「开始录制」；
5. 制造阶跃：`temp_sw 0`（开环降温）→ 温度回落后设置目标 → 再 `temp_sw 1` 闭合；
6. 结束后 CSV 自动落盘，按 `Time(s)` 与 `temp_value` 画曲线，计算：上升时间、超调、稳态静差。

### 9.3 案例要点与经验
- 参数含义要按固件文档来（此例 `temp_kd` 是**电流执行器阻尼**，调大会让电流变钝、超调反而更大，并非微分项）。
- 积分（`ki`）能消静差，但在电流饱和段会 windup、推高超调：`ki≈0.1~0.3` 量级、不宜过大。
- 多次 Δ≈20°C 阶跃实测（本案例环境）：

| kp/ki/kd | 超调 | 稳态 | 备注 |
|---|---|---|---|
| 12/0/2 | +2.0°C | −0.5°C | 纯比例有静差 |
| 8/0.1/2 | +1.6°C | 恢复偏慢 | 超调最低一档 |
| 12/0.3/2 | +4.1°C | ≈0 | 快但冲最高 |
| **10/0.12/2** | **≈+1.5°C** | **≈0** | 本案例推荐 |

- 常见坑：忘发 `temp_sw 1`（看到的是开环降温曲线）；CSV 首行目标值可能是旧值；参数越界会被固件/上位机拒绝。
